## ◈ Install

### Prerequisites

Install [Millennium](https://github.com/SteamClientHomebrew/Millennium) first.

### Theme

```bash
git clone https://github.com/LotsV8pro/lotus-steam.git "$HOME/.steam/steam/steamui/skins/Lotus"
```

Then in Steam → Millennium → Themes → select **Lotus Purple** and refresh.
